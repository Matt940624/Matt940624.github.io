Bio

I'm an undergraduate researcher and software engineer studying Computer Science with a Mathematics minor at Northeastern University. My work lives at the intersection of robotics, control theory, and software systems — from training imitation learning models on physical robot hardware, to building real-time multiplayer platforms in TypeScript.

Currently at the Northeastern Autonomy & Intelligence Lab, I work on data collection infrastructure for ACT (Action Chunking with Transformers) imitation learning, targeting fine-grained manipulation tasks like fiber optic cable insertion. My stack spans ROS2, Zenoh, Gazebo, and custom HDF5 pipelines.

"Build systems that learn from the world — then let the world build better systems."

Academic Interests

▶ Dynamical Systems & Bifurcation Theory

Currently studying index theory, limit cycles, Poincaré-Bendixson theorem, and two-dimensional bifurcations. I use Desmos and Python for phase portrait visualization. Particularly interested in Hopf bifurcations and their connections to oscillatory robot behaviors.

▶ Robotics & Control

Experience with ROS2, Isaac Sim (IsaacLab), F1Tenth autonomous racing, and imitation learning (ACT). Especially interested in combining learning-based methods with classical control for reliable, interpretable robot behavior.

▶ Formal Language Theory & Systems

Strong foundation in DFAs, NFAs, regular expressions, and formal proofs. I enjoy systems programming in C++ and have built a custom shell, among other low-level projects.

Architecture Overview

GameNite is a TypeScript monorepo with shared type definitions ensuring type-safety across client and server. Game logic runs event-driven via Socket.IO, with MongoDB for persistence. The AI bot system uses configurable personality profiles to simulate realistic player behavior in Mafia.

mafia-bot.ts — AI Personality SystemTypeScript
interface BotPersonality { id: 'aggressive' | 'passive' | 'analytical' | 'chaotic'; voteWeight: number; bluffThreshold: number; communicationStyle: StyleConfig; } class MafiaBot implements GamePlayer { decideVote(gameState: GameState): Vote { const suspicion = this.analyzeSuspicion(gameState); return suspicion.score > this.personality.voteWeight ? { target: suspicion.topSuspect } : { target: randomPick(gameState.alivePlayers) }; } }

Habitat Modeling Paper

This paper explores combining deep convolutional neural networks with structured tabular environmental features for predicting species habitat suitability. The hybrid architecture outperforms either modality alone by learning spatial patterns from satellite imagery while incorporating hand-engineered ecological covariates.

📊
Key result: Multi-modal CNN + tabular fusion improved AUC by ~8% over image-only baseline across 12 evaluated species.
